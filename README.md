# demo-swap-site (synthetic)

Stand-in for the project-owned site/repo of **Demo Swap**, a *synthetic* demo project used by [Officially](https://github.com/Ryugi62/officially) (Arkiv: Global Tour Stop entry). Not a real protocol; no real project is represented.

`.well-known/officially.json` states Demo Swap's root key. It lives here, not in the Officially tool repo, so an anchor check reads a different credential than the tool's own code.
